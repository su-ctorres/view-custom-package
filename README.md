# View Customization Package

This repository stores the `YOURCUSTOM_PACKAGE-NAME` VE or NDE customization package and includes a GitHub Action that creates a downloadable zip artifact.

## How to Get Started

1. Delete the `YOURCUSTOM_PACKAGE-NAME` folder and replace with your VE or NDE custom package.
2. Update [`.github/workflows/compress-package.yml`](.github/workflows/compress-package.yml) to change `YOURCUSTOM_PACKAGE-NAME` to your actual package name in both locations.
3. Commit and push your changes to GitHub.

## How to Update the Package

1. Make your changes inside `YOURCUSTOM_PACKAGE-NAME`.
2. Commit and push your changes to `main`.
3. Go to the repository on GitHub.
4. Open the **Actions** tab.
5. Select the latest **Compress customization package** workflow run.
6. Download the `YOURCUSTOM_PACKAGE-NAME` artifact from the run page. The downloaded zip should open directly to a top-level `YOURCUSTOM_PACKAGE-NAME/` folder.

## Manual Zip Build

You can also create the zip manually from the **Actions** tab:

1. Open **Actions**.
2. Select **Compress customization package**.
3. Click **Run workflow**.
4. Download the artifact after the workflow finishes.

## Notes

- The downloadable zip artifact is generated by GitHub Actions and is not committed to the repository.
- Local `.zip` files and `.DS_Store` files are ignored by Git.
- The workflow packages the latest committed version of `YOURCUSTOM_PACKAGE-NAME`.
